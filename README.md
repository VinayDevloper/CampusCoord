# 🎓 CampusCoord

CampusCoord is a modern web platform that enables students to report, track, and resolve campus-related issues efficiently while improving communication between students and the administration.

---

## 🌐 Live Demo

👉 https://campus-coord.vercel.app/register.html

---

## ✨ Features

- 📝 Report Campus Issues
- 🔒 Anonymous Reporting
- 👍 Upvote Issues
- 🙋 Claim Issues
- ✅ Proof Verification
- 📊 Leaderboard
- 👤 User Profile
- 🛡️ Admin Dashboard
- 📱 Responsive Design

---

## 🚀 Installation

```bash
git clone https://github.com/VinayDevloper/CampusCoord.git

cd CampusCoord

pip install -r requirements.txt

uvicorn backend.main:app --reload
```
