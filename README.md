# 🎓 CampusCoord

A modern platform for reporting, tracking, and resolving campus issues collaboratively.

---

## Problem Statement
College complaints usually get lost in WhatsApp chats or informal communication. CampusCoord makes them visible, trackable, and accountable.

## How It Works
1. Student reports an issue
2. Others upvote and discuss it
3. A user claims responsibility
4. Proof is uploaded
5. Community verifies the resolution
